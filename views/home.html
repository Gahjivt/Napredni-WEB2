O aplikaciji

Aplikacija namjerno sadrži dvije ranjivosti. Svaka se uključuje i isključuje checkboxom iznad.

  • Stored XSS: recenzija artikla.
  • Broken Access Control: admin panel (/admin), kontrola pristupa temelji se na JWT-u u kolačiću token.

Svatko tko otvori stranicu dobiva kolačić token, JWT potpisan tajnom JWT_SECRET s podatkom role=user.

Kako izvesti Stored XSS

  1. Označite checkbox "XSS ranjivost UKLJUČENA".
  2. Otvorite "Recenzije artikla" i objavite recenziju: <script>alert(document.cookie)</script>
  3. Pri svakom prikazu stranice izvršit će se skripta i prikazati kolačić. Isto vide i svi ostali posjetitelji jer je recenzija spremljena na poslužitelju.
  4. Uncheckajte checkbox: ista recenzija ispisuje se kao običan tekst, a kolačić je HttpOnly pa ga skripta ne vidi.

Kako izvesti Broken Access Control

  1. Označite checkbox "Broken Access Control ranjivost UKLJUČENA".
  2. Otvorite /admin s običnim tokenom: dobivate 403.
  3. U konzoli preglednika (F12) upišite krivotvoren token (u podacima {"role":"admin"}, potpis proizvoljan): 
    document.cookie = "token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJyb2xlIjoiYWRtaW4ifQ.x;"
  4. Osvježite /admin: poslužitelj ne provjerava potpis pa se prikazuje admin panel.
  5. Uncheckajte checkbox i osvježite stranicu: isti token sada daje 403, jer poslužitelj provjerava potpis. Pristup ima samo ispravno potpisan token s role=admin (gumb "admin" gore izdaje takav token).
